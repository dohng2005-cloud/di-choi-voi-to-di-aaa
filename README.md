# Lời mời đi chơi tối nay 🌙

Website mini mobile-first, không cần backend.

## Chạy
Mở `index.html` trực tiếp trên trình duyệt, hoặc dùng Live Server trong VS Code.

## Cá nhân hóa
Mở `script.js` và sửa object `invitation` ở đầu file:
- title
- subtitle
- time
- location
- planShort

Các câu thoại tương tác cũng nằm ngay trong `script.js`.

## Cấu trúc
- index.html
- styles.css
- script.js

Không có dữ liệu gửi lên server.
